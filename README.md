# Girls Who Code Game Design Track

This repository contains the projects I completed as part of the Girls Who Code Game Design Track. Throughout the track, I learned the basics of game design and interactive storytelling by creating games and projects with different types of player interaction and choices. Each folder contains a project I worked on during the track.

## Projects

| Project | Description |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Collection Game** | Created a game where players collect falling boba pearls into their bubble tea cup. |
| **Choose Your Own Adventure** | Designed an interactive story where players make choices that lead to different paths and endings around a computer hack. |
| **Interactive Avatar** | Built an interactive avatar using basic p5.js shapes. |

## Skills & Technologies

- **Game Design:** Interactive storytelling, game mechanics, branching narratives
- **Programming:** JavaScript

## Getting Started

### Clone the repository

```bash
git clone https://github.com/KaileyLiou/game-design.git
```

### Navigate to a project

```bash
cd cyoa_game
```

### Install dependencies

```bash
pip install pandas numpy matplotlib scikit-learn
```
